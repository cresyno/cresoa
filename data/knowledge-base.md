1. CRESOA OVERVIEW
==================================================

WHAT IS CRESOA?

Cresoa is a business management platform built for Nigerian SMEs.

It helps businesses manage customers, orders and jobs, inventory, production workflows, staff, customer tracking, and other day-to-day business operations from one mobile-first platform.

Cresoa is designed to work across mobile phones, tablets, and desktop computers.

CURRENTLY SUPPORTED BUSINESS TYPES

Cresoa currently supports:

1. Fashion & Custom Wear
2. Repairs & Technical Services

Fashion & Custom Wear is intended for businesses such as:

- Tailors
- Fashion designers
- Custom clothing businesses
- Aso-Ebi coordinators

Repairs & Technical Services is intended for businesses such as:

- Phone repair shops
- Electronics repair shops
- Equipment repair businesses
- Other technical repair businesses

Custom Manufacturing is planned for a future release and should not be described as a currently available industry.

2. GETTING STARTED
==================================================

CREATING AN ACCOUNT

Users can create a Cresoa account through the Cresoa website.

The signup process includes entering an email address, creating a password, and selecting the relevant business type.

The exact available signup options should follow the current application interface.

LOGIN

Users can log in through:

https://cresoa.vercel.app/login

Users provide their registered email address and password.

FORGOTTEN PASSWORD

If a user forgets their password, they can select "Forgot Password" on the login page and follow the password-reset instructions sent to their registered email address.

MULTIPLE BUSINESSES

Users who manage multiple businesses can switch between businesses using the Business Switcher.

The selected business determines which business data is displayed throughout the dashboard.

If the wrong business appears:

1. Confirm the selected business in the Business Switcher.
2. Refresh the page.
3. If the issue continues, log out and log back in.
4. If the problem persists, contact support.

Business data belongs to its respective business and should not be assumed to be shared between businesses.

3. CUSTOMER MANAGEMENT
==================================================

ADDING A CUSTOMER

To add a customer:

1. Open Customers.
2. Select "Add Customer".
3. Enter the customer's available information.
4. Add measurements when relevant to the business.
5. Save the customer.

CUSTOMER SEARCH

Customers can be searched from the Customers page.

Search can be performed using available customer information such as name or phone number.

EDITING CUSTOMER INFORMATION

Open the customer's profile and select the available edit option.

Customer information and measurements can be updated from the customer profile.

7. PRODUCTION WORKFLOW
==================================================

WHAT ARE WORKFLOW STAGES?

Workflow stages represent the steps an order or job moves through from beginning to completion.

DEFAULT FASHION WORKFLOW

Typical default stages are:

1. Order Placed
2. Cutting
3. Sewing
4. Ready for Pickup
5. Delivered

DEFAULT REPAIR WORKFLOW

Typical default stages are:

1. Received
2. Diagnosing
3. Waiting for Parts
4. In Repair
5. Ready for Pickup

CUSTOM WORKFLOW STAGES

Businesses can customize their workflow stages where the feature is available.

Users can configure stages from the relevant workflow settings.

Customization may include:

- Renaming stages
- Reordering stages
- Adding stages
- Removing stages

The exact number of stages permitted should follow the current application implementation.

Do not promise an unlimited number of stages unless the application explicitly supports it.

EXISTING ORDERS AND STAGE CHANGES

Changing the workflow configuration does not automatically mean that existing order data will be rewritten.

If a user asks about a specific existing order after changing stages, provide the documented behavior available in the current platform context.

11. TESSA
==================================================

WHAT IS TESSA?

Tessa is Cresoa's support assistant.

Tessa helps users understand Cresoa, navigate documented features, complete supported tasks, understand plan limits, and troubleshoot common problems.

Tessa does not replace human support when an issue requires account-level investigation or an action unavailable to Tessa.

TESSA ACTION LIMITS

Free:
5 actions per month

Starter:
50 actions per month

Pro:
500 actions per month

Beta:
200 actions per month

Each request to Tessa counts as one action according to the current Cresoa usage policy.

Usage resets according to the application's monthly usage cycle.

The user's current remaining usage should be taken from Platform Context when available.

WHEN TESSA LIMIT IS REACHED

When a user reaches their Tessa action limit, Tessa may no longer respond to additional requests until the usage period resets or the user changes to a plan with additional Tessa capacity.

The user can continue using other Cresoa features according to their plan.

TESSA ACCURACY

Tessa should not invent Cresoa functionality.

If Tessa cannot confidently answer a Cresoa-specific question using the available information, she should say that the information is not currently available and direct the user to appropriate support.

14. DATA AND PLAN CHANGES
==================================================

PLAN LIMITS

Plan limits control how much of a particular resource a business can actively use.

Examples include:

- Number of customers
- Number of orders/jobs
- Number of inventory items
- Number of staff accounts
- Tessa actions

REACHING A LIMIT

When a business reaches a limit, the user may be prevented from creating additional resources until:

- They remove existing resources where appropriate, or
- They move to a plan with greater capacity.

Existing data should not be described as automatically deleted merely because a limit has been reached.

DOWNGRADING

When moving to a lower-capacity plan, the user may have more existing resources than the new plan permits.

In such situations, feature access may be restricted until the account is within the applicable plan limits.

Never promise a specific downgrade mechanism unless it is documented by the current subscription implementation.

18. DATA SAFETY
==================================================

Cresoa's plan-limit behavior is designed so that reaching a plan limit does not automatically mean that existing business data is deleted.

When explaining plan changes, distinguish between:

- Data remaining stored
- Ability to create new data
- Ability to use a particular feature
- Staff access
- Plan capacity

Do not make claims about permanent deletion, backups, restoration, retention periods, or data recovery unless those policies are explicitly documented.
